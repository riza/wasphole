The blind spot

MCP gives agents a surface to explore.

Traditional honeypots watch networks. wasphole watches tool calls, resource reads, prompt-driven recon, and exfiltration attempts from AI agents.

Unauthorized recon has a new shape.

Agents enumerate tools, read resources, retry failed calls, and hunt for secrets through MCP instead of sockets.

Obvious fake servers get fingerprinted.

wasphole generates a unique identity, realistic OS state, and stable cached answers so repeated calls stay believable.

A fake machine with a real memory.

Deploy the lure.

Run wasphole over stdio or HTTP beside your real MCP estate.

transport.type = "http"
instance.mode = "linux"

Quickstart

Drop it where an agent will look.

Configure a believable deployment profile, start the MCP transport, and send alerts into the sink your team already watches.

terminal 
git clone https://github.com/riza/wasphole
cd wasphole
cp config.yaml.example config.yaml

export ANTHROPIC_API_KEY="sk-ant-..."
go run ./cmd/wasphole --config config.yaml

# alert line
{"level":"warn","pattern":"recon","session":"agent-7f2d9e"}
